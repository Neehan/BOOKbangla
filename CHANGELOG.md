# Changelog

## 1.0.1

- Support updated TeX Live 2024 and later, using LaTeXbangla 2.1 or newer.
- Use TeX Gyre Chorus for English chapter quotations; quotation fonts remain configurable.

## 1.0

- First release of the memoir-based book class using LaTeXbangla 2.0.
- Support XeLaTeX and LuaLaTeX, with author-selected fonts and bibliography.
- Write in Bangla or Assamese, with a manual in English and both languages.
- Provide chapter designs, examples, quotations and highlighted boxes.
